# Omkar Sharad Mayekar Portfolio

A research-focused portfolio website for Omkar Sharad Mayekar, built with React + TypeScript + Vite.

## Local development

```bash
npm install
npm run dev
```

The app is available at http://localhost:5173 by default.

## Production build

```bash
npm run build
npm run preview
```

## Deployment

This project is configured for GitHub Pages through the workflow in `.github/workflows/deploy.yml`.

1. Push the project to a GitHub repository.
2. Enable GitHub Pages in the repository settings.
3. Use the default `GitHub Actions` source.
4. Push to the `main` branch to trigger deployment.

The site uses a relative base path for static hosting compatibility.
